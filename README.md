# Snake (C++)
Классическая змейка в консоли на чистом С++, только стандартные библиотеки.


## Возможности

- Управление на стрелочки и WASD
- Еда появляется только на свободных клетках
- Столкновение приводит к проигрышу
- Ускорение игры каждые 10 яблок
- Счёт


## Сборка и запуск

Требуется компилятор с поддержкой C++11 (MinGW/g++) и Windows
(`windows.h`, `conio.h`, `GetAsyncKeyState`):

```bash
g++ Snake.cpp -o Snake.exe
./snake.exe
